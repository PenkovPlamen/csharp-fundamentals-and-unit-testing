# csharp-fundamentals-and-unit-testing
This repository contains programming exercises, unit testing and practical projects completed during Programming Fundamentals and Unit Testing course. The purpose is to document and showcase my learning progress, programming skills, problem-solving techniques and understanding of software testing principles.

TOPICS COVERED: 
• Data Types and Variables - First Steps in Coding, Visual Studio, Data Types Introduction, Variables Introduction,  Input/Output.
• Key Concepts - Arithmetical Operations, Simple Calculations, Formatted Output, Math Operations.
• Simple Conditional Statements - Comparison Operators, Implementing Control-Flow Logic, Logical Operators.
• Complex Conditional Statements - Nested Conditional Statements, Switch-Case,  Logical Operators: And, Or, Not.
• For Loop - Increment and Decrement, For Operator, Loops with a Step.
• While Loop - The Need of While Loop, Control Flow, While vs For Loop.
• Nested Loops - Loops with Special Step, Nested For & While Loops.
• Methods - Declaring and Invoking Methods, Methods with Parameters, Returning Values.
• Arrays - Defining, Reading and Iterating.
• Lists - Defining, List Methods, For-Each Loop.
• Unit Testing and Testing Frameworks, NUnit, The AAA Pattern.
• Unit Testing Methods, Arrays and Lists.
